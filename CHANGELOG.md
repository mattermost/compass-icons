# Changelog

All notable changes to Compass Icons are documented here. Earlier releases are listed on the [GitHub Releases](https://github.com/mattermost/compass-icons/releases) page.

## 0.1.64 - 2026-10-29

-   Added `message-outline` icon
-   Removed hardcoded fill from `ai-summarize` and merged it into a single compound path

## 0.1.63 - 2026-08-21

-   Added `dialpad` icon
-   Updated `summarize` icon

## 0.1.61 - 2026-06-01

-   Added `shield-lock-outline` and `file-help-outline-large` icons
-   Build scripts migrated to native ESM
-   Added `repository` field to `package.json` for npm trusted publishing provenance verification
-   Releases 0.1.54-0.1.60 never reached npm due to a sigstore provenance validation issue introduced when trusted publishing was enabled in 0.1.54. This is the first release since 0.1.53 to publish to npm.
